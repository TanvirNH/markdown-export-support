Everything you need to know about Markdown Export.

Markdown Export converts your document to PDF, PNG, real Word (.docx), HTML, and ePub 3.0. PDF and PNG are free; DOCX, HTML, ePub, batch export, and paper/margin selection are part of Markdown Export Pro.

Yes. Click Open .md in the sidebar, drag a .md file onto the editor, or double-click a .md file in Finder to open it in Markdown Export. Pro users can also run Batch Export to turn a folder of markdown files into PDF, DOCX, HTML, ePub, or PNG files in one pass.

Open the Paper row in the sidebar to pick US Letter, A4, or US Legal with a Narrow / Normal / Wide margin preset. Paper size and margins are part of Markdown Export Pro.

Twelve export themes ship in the app, grouped by use: GitHub, Whitepaper, Report, Technical Docs, Minimal, Academic, Book, Modern, Letterhead, Resume, Dark, and the default. The default theme is free; the other eleven are part of Pro.

Markdown Export Pro is sold via Apple StoreKit as a Monthly subscription, a Yearly subscription, or a one-time Lifetime purchase. Free users get five export credits up front; Pro is unlimited. Tap Restore Purchases in the upgrade window after signing in to the same Apple ID that bought Pro.
